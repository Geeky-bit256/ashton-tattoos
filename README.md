# Ashton Tattoos

A responsive website concept designed for a tattoo artist and illustrator.

## Overview

The goal of this project was to create a clean, visual-first website
that puts the artist's work at the center while making it easy for
potential clients to explore services and get in touch.

## Features

- Responsive design
- Hero section with clear CTA
- Tattoo and drawing services
- Artwork gallery
- WhatsApp contact integration

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

- `/images` — project images and assets
- `/css` — stylesheets
- `/js` — JavaScript functionality
