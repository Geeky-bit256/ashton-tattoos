## Overview

The goal of this project was to create a clean, visual-first website that puts the artist's work at the center while making it easy for potential clients to explore the services and get in touch.

The design focuses on showcasing the artist's work, communicating the available services clearly, and creating a simple path from discovering the portfolio to contacting the artist.

## Features

- 📱 Responsive design
- 🎨 Visual-first portfolio layout
- 🖼️ Artwork gallery
- ✏️ Tattoo and drawing services
- 💬 WhatsApp contact integration
- 🔗 Clear calls-to-action
- 📱 Mobile-friendly navigation

## Technologies

- HTML5
- CSS3
- JavaScript

## Design Goals

- **Showcase the artwork** — Make the artist's work the primary focus of the experience.
- **Keep navigation simple** — Allow visitors to move between important sections without unnecessary complexity.
- **Make contacting the artist easy** — Use clear calls-to-action and WhatsApp integration.
- **Provide a responsive experience** — Ensure the website works well across desktop and mobile devices.
